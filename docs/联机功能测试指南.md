# 联机功能测试指南

你的游戏已经实现了完整的联机功能！包括：

- ✅ 手动/AI 混合对局

## 🚀 快速开始

### 1. 启动服务器

```bash
npm run server
```

服务器将在 `ws://localhost:9090` 启动。你会看到：
```
🚀 简单游戏服务器已启动: ws://localhost:9090
```

### 2. 启动客户端（应用）

在新的终端窗口：

```bash
npm start
```

然后选择你的平台（Web/Android/iOS）。

### 3. 切换到联机模式

在应用主界面，点击顶部的 **"联机"** 按钮，切换到联机模式。

## 📱 单设备测试（快速验证）

你可以在一个设备上测试联机功能：

1. **启动服务器**：`npm run server`
2. **启动应用**：`npm start` → 选择 Web
3. **切换到联机模式**：点击"联机"按钮
4. **自动加入**：应用会自动：
   - 创建/加入房间 `dev-room-1`
   - 添加你的手动座位
   - 自动填充 5 个 AI 玩家
5. **点击"准备"**：所有 AI 自动准备
6. **点击"开始游戏"**：游戏开始！

## 🌐 多设备测试（真实联机）

### 测试场景：两个玩家 + 4 个 AI

#### 设备 1（玩家 A）
1. 启动应用并切换到联机模式
2. 应用会创建房间并加入
3. 点击"准备"

#### 设备 2（玩家 B）
1. 启动应用并切换到联机模式
2. **需要修改代码**：在 `app/index.tsx` 第 86 行，将房间 ID 改为玩家 A 的房间 ID
   ```typescript
   const onlineVm = useNetworkRoomGame("dev-room-1", "玩家B");
   ```
3. 应用会加入同一个房间
4. 点击"准备"

#### 开始游戏
- 当 6 名玩家都准备好后，任意玩家点击"开始游戏"
- 所有客户端实时同步游戏状态

## 🔧 配置说明

### 修改服务器端口

编辑 `tools/server/simpleServer.ts`：
```typescript
const port = Number(process.env.PORT ?? 9090); // 改成你想要的端口
```

或者启动时指定：
```bash
PORT=8080 npm run server
```

### 修改客户端连接地址

如果服务器不在本地，需要修改 WebSocket 连接地址。

查找使用 `RoomGatewayClient` 的地方，修改 WebSocket URL：
```typescript
// 例如：连接到远程服务器
const client = new RoomGatewayClient("ws://192.168.1.100:9090");
```

### 修改房间设置

在 `app/index.tsx` 第 86 行：
```typescript
const onlineVm = useNetworkRoomGame(
  "你的房间ID",    // 房间 ID
  "你的昵称"       // 玩家昵称
);
```

## 💡 技术架构说明

### 通信协议

客户端 ↔ 服务器使用 WebSocket + JSON 协议：

```typescript
// 客户端发送命令
{
  "requestId": "uuid",  // 可选，用于关联响应
  "command": {
    "type": "JOIN_ROOM",
    "roomId": "dev-room-1",
    "displayName": "玩家1"
  }
}

// 服务器响应
{
  "kind": "COMMAND_RESULT",
  "requestId": "uuid",
  "result": { ... }
}

// 服务器推送事件
{
  "kind": "GATEWAY_EVENT",
  "event": {
    "kind": "ROOM_STATE_UPDATED",
    "roomId": "dev-room-1",
    "state": { ... }
  }
}
```

### 命令列表

- `JOIN_ROOM` - 加入房间
- `READY_UP` - 准备
- `CANCEL_READY` - 取消准备
- `START_GAME` - 开始游戏
- `PLAY_CARDS` - 出牌
- `PASS` - 过牌
- `GET_ROOM_STATE` - 获取房间状态

### 事件列表

- `ROOM_JOINED` - 成功加入房间
- `ROOM_STATE_UPDATED` - 房间状态更新
- `PLAYER_READY_CHANGED` - 玩家准备状态变化
- `GAME_STATE_UPDATED` - 游戏状态更新
- `ERROR` - 错误
