## 📝 已完成的改进

### 服务器端（SimpleGameServer.ts）

#### 1. **GameSession 增强**
```typescript
- playerId: 游戏中的玩家 ID (P1, P2, etc.)
- pendingDecision: 玩家提交的出牌决策
- decisionResolved: 决策是否已被处理标记
```

#### 2. **GameRoom 游戏逻辑**
```typescript
- startGame(): 创建游戏引擎并为每个玩家设置决策控制器
- submitDecision(): 提交决策并推进游戏
- advanceGame(): 自动推进游戏直到需要玩家决策
- getCurrentTurnSession(): 获取当前需要决策的玩家
```

#### 3. **完善的广播机制**
```typescript
- broadcastRoomState(): 广播房间状态到所有玩家
- convertToRoomState(): 将服务器格式转换为客户端格式
- 发送 ROOM_STATE_UPDATED 和 ROOM_JOINED 事件
```

#### 4. **游戏状态同步**
- 房间摘要现在包含完整的 GameState
- 每次出牌后自动广播更新
- 支持 GET_ROOM_STATE 命令获取当前状态

### 场景 1：完整游戏流程（6 人真实游戏）

**目标：** 测试从准备到游戏结束的完整流程

**步骤：**

1. **所有玩家加入房间**
   - 在 6 个浏览器窗口中，都切换到"联机"模式
   - 确认每个窗口都显示"已连接"
   - 确认玩家列表显示 6 个玩家

2. **全员准备**
   - 在每个窗口点击"准备"按钮
   - 观察准备状态：应该显示 "1/6", "2/6", ... "6/6"
   - 最后一个玩家准备后，"开始游戏"按钮应该变为可用

3. **开始游戏**
   - 点击"开始游戏"按钮
   - 观察服务器日志：
     ```
     [GameRoom] 游戏已开始，玩家: [...]
     👉 轮到 xxx 出牌（阵营 A｜手牌 27）
     ```
   - 客户端应该显示游戏状态更新

4. **出牌流程**
   
   **当前回合玩家：**
   - 查看自己的手牌
   - 选择要出的牌（如果支持手牌选择UI）
   - 点击"出牌"或"过牌"按钮
   
   **其他玩家：**
   - 应该看到"等待 xxx 出牌"
   - 看到当前玩家的头像有高亮标记
   
   **服务器日志：**
   ```
   [GameRoom] 玩家 xxx 提交决策: 3张牌
   ✅ xxx 出牌：♠3 ♠4 ♠5
   👉 轮到 yyy 出牌（阵营 B｜手牌 24）
   ```

5. **观察游戏推进**
   - 游戏应该自动推进到下一个玩家
   - 每个玩家的回合都会在所有客户端同步显示
   - 游戏状态面板应该显示：
     - 当前轮次
     - 最近的出牌
     - 手牌数变化

6. **游戏结束**
   - 某个玩家出完所有手牌
   - 服务器日志：
     ```
     🎉 xxx 已出完所有手牌！（第 1 位）
     🏁 阵营 A 的玩家全部出完，游戏立即结束并结算胜负。
     ```
   - 客户端显示游戏结果面板

**预期结果：**
- ✅ 游戏从开始到结束流畅运行
- ✅ 所有客户端状态同步
- ✅ 没有控制台错误
- ✅ 服务器没有崩溃

## 🔍 调试技巧

### 1. 查看 WebSocket 消息

**浏览器开发者工具 → Network → WS:**
- 筛选 `ws://localhost:9090`
- 查看 Messages 标签
- 确认消息流：
  ```
  → { kind: "JOIN_ROOM", roomId: "default-room", ... }
  ← { kind: "ROOM_JOINED", state: {...} }
  → { kind: "READY_UP", roomId: "default-room" }
  ← { kind: "ROOM_STATE_UPDATED", state: {...} }
  → { kind: "START_GAME", roomId: "default-room" }
  ← { kind: "ROOM_STATE_UPDATED", state: {...} }
  → { kind: "PLAY_CARDS", cards: [...] }
  ← { kind: "ROOM_STATE_UPDATED", state: {...} }
  ```

**正常流程日志：**
