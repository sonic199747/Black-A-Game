## 📡 通信协议

### 客户端 → 服务器（命令）

```typescript
// 加入房间
{
  "requestId": "uuid",
  "command": {
    "type": "JOIN_ROOM",
    "roomId": "room-1",
    "displayName": "玩家1"
  }
}

// 准备
{
  "command": {
    "type": "READY_UP",
    "roomId": "room-1"
  }
}

// 开始游戏
{
  "command": {
    "type": "START_GAME",
    "roomId": "room-1"
  }
}

// 出牌
{
  "command": {
    "type": "PLAY_CARDS",
    "roomId": "room-1",
    "cards": [...]
  }
}

// 过牌
{
  "command": {
    "type": "PASS",
    "roomId": "room-1"
  }
}
```

### 服务器 → 客户端（事件）

```typescript
// 连接成功
{
  "kind": "READY",
  "clientId": "uuid"
}

// 命令执行结果
{
  "kind": "COMMAND_RESULT",
  "requestId": "uuid",
  "command": "JOIN_ROOM",
  "result": { ... }
}

// 房间状态更新
{
  "kind": "GATEWAY_EVENT",
  "event": {
    "kind": "ROOM_STATE_UPDATED",
    "roomId": "room-1",
    "state": {
      "roomId": "room-1",
      "players": [...],
      "phase": "lobby",
      "gameSnapshot": null
    }
  }
}

// 游戏状态更新
{
  "kind": "GATEWAY_EVENT",
  "event": {
    "kind": "GAME_STATE_UPDATED",
    "roomId": "room-1",
    "gameState": {
      "players": [...],
      "currentPlayerIndex": 0,
      "lastPlay": null,
      ...
    }
  }
}

// 错误
{
  "kind": "COMMAND_ERROR",
  "error": "错误信息"
}
```

## 🎮 游戏状态管理

### 房间状态（RoomState）

```typescript
interface RoomState {
  roomId: string;           // 房间 ID
  ownerId: string | null;   // 房主 ID
  players: Array<{          // 玩家列表
    clientId: string;
    displayName: string;
    seat: number;
    isReady: boolean;
  }>;
  phase: "lobby" | "playing" | "finished";  // 房间阶段
  gameSnapshot: GameState | null;           // 游戏快照
}
```

### 游戏状态（GameState）

```typescript
interface GameState {
  players: Player[];            // 玩家列表
  currentPlayerIndex: number;   // 当前玩家索引
  lastPlay: Play | null;        // 上一次出牌
  lastPlayOwnerIndex: number | null;
  passesInRound: number;        // 本轮过牌次数
  finishCount: number;          // 已出完玩家数
  gameOver: boolean;            // 游戏是否结束
  result: Result | null;        // 游戏结果
}
```

## 🔐 会话管理

### 客户端会话（GameSession）

```typescript
class GameSession {
  readonly id: string;              // 会话 ID（唯一标识）
  readonly displayName: string;     // 显示昵称
  isReady: boolean;                 // 是否准备
  seatIndex: number | null;         // 座位索引
  playerId: string | null;          // 游戏中的玩家 ID (P1, P2, ...)
  pendingDecision: Card[] | null;   // 待提交的决策
  decisionResolved: boolean;        // 决策是否已处理
}
```

### 房间实例（GameRoom）

```typescript
class GameRoom {
  readonly id: string;              // 房间 ID
  readonly maxPlayers: number;      // 最大玩家数
  private sessions: GameSession[];  // 会话列表
  private gameWrapper: GameWrapper | null;  // 游戏引擎
  private status: "lobby" | "playing" | "finished";  // 状态
  
  // 方法
  addPlayer(session: GameSession): void;
  setReady(sessionId: string, isReady: boolean): void;
  startGame(): void;
  submitDecision(sessionId: string, cards: Card[] | null): boolean;
  getState(): GameState | null;
}
```

## 🎯 技术要点

### 1. 状态同步
- 服务器为权威状态源
- 客户端接收并显示服务器状态
- 所有操作通过服务器验证

### 2. 决策控制
- 人类玩家：等待客户端提交决策
- AI 玩家：服务器自动调用 AI 决策函数

### 3. 回合推进
- 自动推进 AI 回合
- 遇到人类玩家时暂停，等待决策
- 决策提交后继续推进

### 4. 房间隔离
- 每个房间独立运行
- 不同房间互不干扰
- 支持多房间并行

### 5. 错误处理
- 命令验证（牌型、回合检查）
- 网络错误重试
- 断线提示和重连
